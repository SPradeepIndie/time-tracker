## Module A — Task Management

### ✅ Implemented

#### Task Types
| Type | Description |
|------|-------------|
| `unallocated` | Default. No scheduled time. Created immediately. |
| `allocated` | Same-day only. Has a start/end time or duration in 45-min blocks. |

#### Time Allocation (Allocated Tasks Only)
Three input modes are supported:
1. **Start Time + End Time** — `TimeInputMode: 'start-end'`
2. **Start Time + Duration** — `TimeInputMode: 'start-duration'`
3. **Duration Only** — `TimeInputMode: 'duration-only'` (implicitly `startTime = now`)

> **Block size:** 1 block = **45 minutes**. Duration is `blockMultiplier × 45`.

#### Time Constraints
- **Start Time:** Must be `now` or future. Past times are invalid.
- **End Time:** Must be strictly after both `now` and `Start Time`.
- **Long-term scheduling** (multi-day or monthly) is **not supported**.

#### State Machine

**Unallocated Track:**
```
[created] → [pending] → [in-progress] → [completed]
```

**Allocated Track:**
```
[created] → [time-allocated] → [in-progress] → [completed]
```

| Status | Trigger |
|--------|---------|
| `created` | Automatic on task creation |
| `pending` | Manual user action (unallocated only) |
| `time-allocated` | Automatic when valid start/end time is attached |
| `in-progress` | Automatic when system clock matches `startTime` (allocated); manual (unallocated) |
| `completed` | **Always requires explicit user action** |

#### Task Priority
`low` | `medium` | `high`

#### Tags
- Predefined tag chips + ability to type custom tags.

## Module D — Analytics Dashboard

### ✅ Implemented

#### Daily Metrics

| Metric | Formula |
|--------|---------|
| **T_prod** (Productivity Time) | `Σ duration_minutes(i)` for completed/in-progress tasks |
| **G_day** (Goal Hit Rate) | `G_completed / G_total × 100%` |
| **R_day** (Routine Hit Rate) | `Σ A_checked / Σ A_total × 100%` |
| **P_day** (Overall Progress) | `W1 × TaskRate + W2 × G_day + W3 × R_day` |

**Default Weights:**
```
W1 = 0.40  (Tasks)
W2 = 0.35  (Goals)
W3 = 0.25  (Routines)
```

#### Weekly Metrics

| Metric | Formula |
|--------|---------|
| **P_category(c)** | `(Completed goals + sub-goals in c) / Total × 100%` |
| **7-Day Rolling History** | Daily `P_day`, `G_day`, `R_day`, `TaskRate` over last 7 days |
| **Weekly Averages** | Mean of each metric across the 7-day window |

#### UI Components

- **Hero card** — big `P_day` percentage with formula shown
- **T_prod card** — formatted as `Xh Ym`
- **3 Gauge charts** — vertical fill bars for Tasks / Goals / Routines
- **Formula breakdown** — per-metric progress bars with calculation
- **7-day stacked bar chart** — one column per day, color-coded by metric
- **Category matrix** — `P_category` per weekly goal category

## Notifications System

### ✅ Implemented

All 7 notification types are implemented in `notificationService.ts`:

| ID | Type | Schedule |
|----|------|----------|
| A | Unallocated task review | 3× daily: **8 AM, 1 PM, 6 PM** (5h gap, within 8AM–11PM window) |
| B | In-progress task reminder | Every **45 minutes** while a task is in-progress |
| C | Allocated task start alert | Fires at exact `startTime` of task |
| D | Allocated task expiry alert | Fires at exact `endTime` of task |
| E | Daily goal planning reminder | Configurable nightly (user sets hour:minute) |
| F | Daily goal verification | Fixed: **9:00 AM** and **4:00 PM** daily |
| G | Routine reminder matrix | One daily trigger per routine reminder entry |
